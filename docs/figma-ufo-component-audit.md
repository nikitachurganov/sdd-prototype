# Аудит компонентов Figma и UFO DNSUI Web Library

Дата среза: 22 июля 2026 года. Область проверки: секция Figma `176:6552` и текущая реализация экрана загрузки документов в `src/App.vue` / `src/style.css`.

## Просмотренные состояния

- Desktop и mobile: пустой пакет документов.
- Desktop и mobile: пакет с файлами, выбор одного/нескольких файлов, массовые действия, меню и длинный список.
- Добавление файлов: загрузка, частичный успех, ошибки, завершение и свёрнутое состояние уведомления.
- Drag-and-drop: активная зона добавления файлов.
- Предпросмотр: desktop split-view, mobile full-screen, выбор и перелистывание файлов, масштаб и страницы.
- Кадрирование изображения: исходное и увеличенное состояния.
- Успешная отправка пакета и snackbar с переходом к пакету.

| Tabs | `@dns-modules/base-ui-tabs` | Навигация в шапке |

| Popover | `@dns-modules/popover` | Desktop-статус добавления файлов |

Пакеты DNSUI подключены, но часть их внешнего вида всё ещё переопределяется локальными классами. При перевёрстке стоит оставить в CSS только раскладку и предметные состояния, не дублируя внутренние стили компонентов библиотеки.

## Есть в UFO, но сейчас заменено самописной реализацией

Наличие следующих типов подтверждено поиском по **UFO DNSUI Web Library**. Для компонентов без уже установленного аналога нужно отдельно уточнить точное имя и API npm-пакета; node id намеренно не фиксируются.

| Компонент UFO | Текущая реализация в проекте | Следующее действие |
| --- | --- | --- |
| Tooltip | `title` и отдельные подписи | Зависимость уже установлена; использовать `@dns-modules/base-ui-tooltip` для иконочных действий и обрезанных имён |
| Search input | Поиск внутри списка выбора файла из макета сейчас отсутствует | Найти и подключить пакет UFO Search input, затем встроить поиск в список документов для предпросмотра |
| Alert | Самописный блок ошибок загрузки | Найти пакет UFO и собрать сообщение на Alert |
| List row | Самописные строки файлов | `@dns-modules/list-row` сейчас только транзитивный; добавить прямую зависимость и использовать как основу мобильной строки |
| Spinner | CSS-спиннер `.upload-activity__spinner` | Найти пакет UFO и заменить локальную анимацию |
| Status | Локальные SVG-иконки успеха/ошибки | Найти пакет UFO и унифицировать статусы загрузки |
| File input | Скрытый нативный input и отдельная кнопка | Найти пакет UFO; сохранить текущую валидацию и множественный выбор |
| Expansion | Самописное раскрытие блока ошибок | Найти пакет UFO и заменить управление раскрытием |
| Library icons | Локальный SVG sprite и `<use>` | `@dns-modules/font-icon` сейчас только транзитивный; добавить прямую зависимость и заменить существующие glyphs |

## Не найдено как отдельный компонент UFO

Эти элементы допустимо оставить предметными компонентами проекта. Их следует собирать из DNSUI-примитивов и токенов, но не переносить в UFO без отдельного решения дизайн-системы.

| Предметный компонент | Рекомендованная граница |
| --- | --- |
| Data table | Таблица файлов, её колонки, выбор и массовые операции |
| Empty state | Тексты и композиция пустого пакета для desktop/mobile |
| Dropzone | Состояние перетаскивания и логика приёма документов |
| Document/PDF preview | Просмотр документа, навигация, масштаб и страницы |
| Crop stage | Canvas кадрирования и его предметная логика |

## Правило дальнейшей реализации

Если элемент найден в UFO DNSUI Web Library, источником должен быть библиотечный компонент и соответствующий `@dns-modules/*` пакет. Локальный код отвечает только за раскладку, данные и предметное поведение. Если компонента в UFO нет, он остаётся в проекте как локальная композиция из библиотечных примитивов и токенов.
